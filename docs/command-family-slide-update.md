# PPT Update: Command Families

This update adds command-family slides to every overview/phase deck.

Focus:
- command option variants: `id -u`, `id -g`, `id -G`, `id -nG`
- filtering and text processing: `grep`, `sed`, `awk`
- system inspection: `systemctl`, `journalctl`, `ip`, `ss`, `df`, `du`, `lsblk`, `findmnt`, `ps`, `lsof`
- recovery/comparison: `tar`, `rsync`, `diff`, `sha256sum`

Teaching rule:
Scenario → Question → Command variant → Output meaning → Record → Verify → Rollback/Reset.
