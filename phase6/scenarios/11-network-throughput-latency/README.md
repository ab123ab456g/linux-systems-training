# 確認 Network throughput / latency

## 目的
區分 host/link/network/app

## 操作原則
- 先建立或讀取 baseline
- measure
- isolate
- 必要時 tune
- 用相同 workload verify
- monitor
- 若結果變差則 rollback

## 學生交付
- measurement evidence
- bottleneck conclusion
- before/after result
- rollback result（若有）
- final note
