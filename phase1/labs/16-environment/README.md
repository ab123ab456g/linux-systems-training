# Lab 16 — Environment

練習 env / printenv / export / unset / PATH。

## 建議操作順序

1. `./prepare.sh`
2. `export PHASE1_LAB_VAR=one`
3. `printenv PHASE1_LAB_VAR`
4. `export PHASE1_LAB_VAR=two`
5. `./verify.sh value two`
6. `unset PHASE1_LAB_VAR`
7. `./verify.sh absent`

## Command family

請配合 PPT 該 Lab 後面的 command family 頁面，先做最小操作，再展開參數族。
