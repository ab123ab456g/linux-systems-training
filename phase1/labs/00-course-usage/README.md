# Lab 00 — 課程使用方式

學會 prepare / manual operation / native check / verify / rollback / reset / record 的角色。

## 建議操作順序

1. `執行 ./prepare.sh`
2. `執行 ../../../common/scripts/record.sh phase1 00 before`
3. `執行 ./verify.sh`
4. `執行 ../../../common/scripts/record.sh phase1 00 after`
5. `執行 ../../../common/scripts/record.sh phase1 00 diff`

## Command family

請配合 PPT 該 Lab 後面的 command family 頁面，先做最小操作，再展開參數族。
